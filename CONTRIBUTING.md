# Contributing to Delentia MCP

Thank you for your interest in contributing to the **Delentia Sovereign AI Operating System MCP Gateway**!

## Development & Submissions

1. **Bug Reports & Feature Requests:**
   - Use [GitHub Issues](https://github.com/delentia-labs/delentia-mcp/issues) to report bugs or request new tool bindings.
2. **Client Integrations:**
   - Pull Requests adding configuration examples or connectors for new AI IDEs, agent runtimes, or frameworks are welcome.
3. **Core Sovereign Architecture:**
   - The core mathematical engine (ZK-FDIA, RCT-7, Delta Engine, and JITNA) is maintained by Delentia Labs under Chief Architect Ittirit Saengow.

## Code of Conduct

Please treat all members of the community with respect, professional rigor, and collaborative goodwill.
