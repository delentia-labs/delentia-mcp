# Security Policy

## Reporting Security Vulnerabilities

The Delentia Labs team takes the security and integrity of the **Delentia Sovereign AI Operating System** with paramount seriousness.

If you believe you have discovered a vulnerability in the FDIA Security Gate, ZK parameter verification, or any Delentia MCP server, please follow our responsible disclosure process:

1. **Do not** create a public GitHub issue.
2. Email your vulnerability report to: `founder@delentia.com` and `security@delentia.com`.
3. Include detailed steps to reproduce the issue, including request payloads, target endpoints, and observed behavior.

### Supported Versions
| Version | Supported |
| :--- | :--- |
| 2.0.x | Yes |
| < 2.0.0 | No |

We appreciate the responsible efforts of security researchers in helping maintain mathematical sovereignty for autonomous AI agents.
